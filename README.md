## 🚀 About The Project
This is a cool web-based tool that converts any image into a **Matrix-style Binary Code (0s and 1s)** while preserving the original colors of the photo.

This project is built purely using **HTML, CSS, and JavaScript**. No server is used—everything is processed locally within your browser, ensuring your photos remain private 🔒.

### ✨ Features
* **Real Color Preservation:** The binary digits take the exact color of the original pixels.
* **High Resolution:** High text density ensures the image remains clear and recognizable.
* **Client-Side Processing:** Images are processed instantly in the browser without uploading to a server.
* **Instant Download:** Save your Matrix avatar as a PNG with a single click.

## 🛠️ How to Use

https://rehan5039.github.io/Binart/ultimate_matrix_effect.html

1.  **Clone the repository** or download the ZIP file:
    ```bash
    git clone https://github.com/rehan5039/Binart.git
    ```
2.  **Open** the `ultimate_matrix_effect.html` file in any modern web browser (Chrome, Edge, Firefox, etc.).
3.  Click on **"Choose File"** and select your photo.
4.  Wait for the processing to finish (larger images may take a few seconds).
5.  Click **"Download Image"** to save your new Matrix-style photo!
